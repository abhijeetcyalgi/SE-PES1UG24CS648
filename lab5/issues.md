# Lab 5: Static Code Analysis — Issues Log

This document records the static code analysis findings discovered by **Bandit**, **Pylint**, and **Flake8** on `bank_account_system.py`, prioritized by severity (High and Medium first).

## Identified Issues and Resolutions

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| **B605: Command Injection via Shell** | Security (High Severity) | 55 | Calling `os.system("echo Backup complete: " + filename)` starts a shell process with string concatenation, allowing arbitrary shell command injection if `filename` is user-controlled. | Replaced `os.system()` with Python's built-in `print(f"Backup complete: {filename}")` and secure file handling, eliminating shell execution entirely. |
| **B324: Insecure Cryptographic Hash (MD5)** | Security (High Severity) | 44 | MD5 (`hashlib.md5`) is cryptographically broken, susceptible to collision attacks, and insecure for password/PIN hashing. | Replaced `hashlib.md5` with SHA-256 (`hashlib.sha256(pin.encode("utf-8")).hexdigest()`), a robust cryptographic hashing algorithm. |
| **B307 / W0123: Unsafe `eval()` Execution** | Security / Bug (Medium Severity) | 39 | `eval(expr)` dynamically evaluates arbitrary Python code from the `expr` parameter, enabling remote code execution (RCE) and code injection. | Replaced `eval()` with a safe Abstract Syntax Tree (AST) evaluator using Python's `ast` module that restricts evaluation strictly to safe mathematical operators and authorized identifiers (`bal`). |
| **B110 / W0702 / E722: Bare `except` with `pass`** | Security / Code Smell (Low Severity) | 22-23 | Bare `except:` catches all exceptions indiscriminately (including `KeyboardInterrupt` and `SystemExit`) and silently suppresses errors using `pass`, masking genuine bugs. | Caught specific exceptions `(KeyError, TypeError)` and implemented explicit validation with clear return values instead of silent failure. |
| **B311: Cryptographically Insecure Pseudo-Random Generator** | Security (Low Severity) | 48 | Standard `random.randint()` uses the Mersenne Twister PRNG, which is completely predictable and unsafe for security tokens and PINs. | Replaced `random.randint()` with the cryptographically secure `secrets.SystemRandom().randint(1000, 9999)`. |
| **B105: Hardcoded Credential / Secret Token** | Security (Low Severity) | 59 | Sensitive administrative token `SUPER_SECRET_BANK_TOKEN_2026` was hardcoded as a plain string in source code. | Loaded the admin token safely from environment variables using `os.getenv("ADMIN_TOKEN", "SUPER_SECRET_BANK_TOKEN_2026")`. |
| **W0102: Mutable Default Argument** | Bug / Quality (Pylint Warning) | 11 | `transactions=[]` assigns a mutable empty list as a default parameter, which is shared across all invocations of the function rather than per instance. | Changed default parameter to `transactions=None` and initialized `transactions = []` inside the function body. |
| **W1514 / R1732: Unmanaged File Resource & Unspecified Encoding** | Quality / Resource Leak (Pylint) | 52-54 | `f = open(filename, "w")` without a context manager risks leaving file descriptors open if an error occurs, and omits explicit platform-independent encoding. | Used a `with open(filename, "w", encoding="utf-8") as file_handle:` context manager for deterministic resource disposal and explicit UTF-8 encoding. |
| **F401 / W0611: Unused Module Import** | Quality / Dead Code (Flake8 / Pylint) | 6 | `sys` was imported into the global namespace but never referenced anywhere in the script. | Removed `import sys` to clean up namespace clutter. |
| **F841 / W0612: Unused Local Variables** | Quality / Dead Code (Flake8 / Pylint) | 27, 38 | `service_fee = 2.50` in `withdraw()` and `bal` in `compute_bonus()` were assigned but never utilized in Python AST scope. | Removed unused `service_fee` variable and properly wired `bal` into the AST expression evaluator. |
| **C0103: Non-snake_case Function Name** | Style / Convention (Pylint) | 11 | `createAccount` violates PEP 8 and Pylint snake_case function naming convention. | Renamed function to `create_account` and provided backwards-compatible alias `createAccount = create_account`. |
| **C0121 / E711: Equality Comparison to `None`** | Style / Convention (Pylint / Flake8) | 28 | `account_data.get(acc_id) == None` uses value equality instead of identity comparison for singletons. | Changed comparison to `account_data.get(acc_id) is None`. |
| **E501: Line Length Violation** | Formatting / Style (Flake8) | 15 | Line 15 exceeded the PEP 8 recommended maximum line length of 79 characters (89 characters). | Wrapped formatted string across multiple lines adhering strictly to the <= 79 characters rule. |
| **C0116: Missing Function & Module Docstrings** | Documentation (Pylint) | Multiple | Functions lacked descriptive docstrings explaining their purpose, parameters, and behaviors. | Added concise, descriptive docstrings for all functions and the module. |
